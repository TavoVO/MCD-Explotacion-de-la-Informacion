# MSc Data Science — Information Exploitation

Coursework and projects from the **Information Exploitation** course in the MSc in Data Science program.

## Topics

- Exploratory data analysis
- Data preparation and descriptive analysis
- Business and ecommerce datasets
- Indicator design and scenario analysis
- Reproducible Jupyter notebooks

## Activities

- **Activity 1:** hotel booking demand analysis
- **Activity 2:** ecommerce session and purchase-behavior analysis
- **Activity 2.2:** indicator construction and deterministic/probabilistic scenario analysis

## Technologies

Python, Jupyter Notebook, Pandas, NumPy, data visualization, and exploratory analysis.

## Repository status

The local workspace is organized into `activities/`, `deliverables/`, and `materials/`. Coursework files will be published after a final review for data and academic privacy.
